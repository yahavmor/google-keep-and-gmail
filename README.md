# KeepMail

A Gmail and Google Keep clone in one React app: an email client and a notes board.

**Live demo:** https://yahavmor.github.io/google-keep-and-gmail/

## Mail

- Folders: inbox, sent, drafts, starred and trash
- Compose, read and unread, star, and move to trash
- Search, filter and sort, with pagination
- Mail details with next and previous navigation

## Notes

- Text, image and to-do list notes
- Note colors and pinning
- Filter notes from the side menu

## Tech

- React and React Router, loaded in the browser (no build step)
- Data kept in localStorage through an async storage service
- An event bus for app-wide messages

## Run locally

Serve the folder with any static server (for example the VS Code Live Server extension) and open `index.html`.
